# JetLag-Ninja

JetLag-Ninja 是一个开源时差矫正项目，目标是基于以下三类方法构建可复现、可扩展的免费替代方案：

- **Eastman & Burgess**：以光照/避光和褪黑素干预为核心的相位调整策略。
- **Timeshifter 思路**：将航班信息与个体节律偏好结合，生成可执行的日程建议。
- **Entrain 优化控制**：使用节律模型与约束优化，在可行条件下最小化时差恢复时间与不适成本。

## 目标

1. 提供可解释的时差纠正建议（睡眠、光照、咖啡因、褪黑素窗口）。
2. 支持东行/西行、跨多时区、多段航班场景。
3. 形成可验证的开源算法实现，逐步替代同类有偿软件在核心功能上的能力。

## 当前状态

- [ ] 实现基础相位估计模型（Eastman & Burgess规则）
- [ ] 增加基于优化的计划生成（Entrain风格控制目标）
- [ ] 输出日历化执行方案与可视化对比
- [ ] 加入回测与场景测试

## 设计原则

- **开源优先**：算法与参数可审计、可复用。
- **可解释性**：每条建议都应有可追溯依据。
- **安全边界**：避免给出超出常规健康建议范围的高风险指令。
